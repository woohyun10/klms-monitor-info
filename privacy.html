개인정보 처리 안내

KLMS Monitor는 계정 소유자의 개인용 과목 보고 자동화입니다. Gmail 읽기 권한 자체는 전체 메일을 읽을 수 있는 권한입니다. 구현은 KAIST SSO 발신자의 본인 인증번호 메일만 검색하며 새 인증번호를 정상 로그인 화면에 입력합니다. 인증번호를 보고서나 과목 기록에 저장하지 않습니다.

Gmail 발송 권한은 연결된 계정 소유자에게 과목별 보고서 또는 실행 실패 안내를 보내는 데 사용합니다. 연결 계정과 수신 계정이 일치하지 않으면 발송하지 않습니다.

로그인 비밀번호와 Gmail OAuth 인증정보는 소유자의 비공개 GitHub 저장소 Actions Secrets에 저장합니다. 작업 중 실행기에 전달되며 공개 코드에 포함하지 않습니다. 과목 공지, 제출 상태와 보고서는 비공개 저장소에 보관하고, 성공 실행의 임시 결과물은 7일 보관합니다. 과목 기록은 소유자가 삭제할 때까지 유지됩니다. 보고 메일은 소유자의 Gmail에 남습니다.

과목 내용의 정리를 위해 OpenAI API를 사용합니다. Gmail 인증메일과 인증정보는 인증 보조 도구에서 처리하고 모델에 반환하지 않습니다. GitHub, Google, OpenAI는 각각 해당 서비스를 제공하는 데 필요한 데이터를 처리합니다. 광고나 데이터 판매에 사용하지 않습니다.

소유자는 Google 계정의 연결된 앱 관리에서 접근을 철회하고, GitHub Secrets 및 기록과 Gmail 보고 메일을 삭제할 수 있습니다. 사용 문의는 본인 계정 소유자가 관리합니다.

KLMS Monitor의 Google 사용자 데이터 사용과 다른 앱으로의 전송은 Google API Services User Data Policy의 Limited Use 요구사항을 따릅니다.
